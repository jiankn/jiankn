# 👋 Hi, I'm the builder behind [LTD Atlas](https://ltdatlas.com)

## 🔍 What is LTD Atlas?

**[LTD Atlas](https://ltdatlas.com)** is a data-driven database tracking **200+ AppSumo lifetime deals** — so you can see which products survived, which pivoted to subscription, and which shut down.

### 📊 Key Data Points We Track

| Metric | What It Tells You |
|--------|-------------------|
| **Survival Status** | Is the product still alive, pivoted, or dead? |
| **Pricing Evolution** | How did pricing change from LTD to subscription? |
| **Success Score** | 0-100 score predicting long-term viability |
| **Indie-Friendly Score** | How replicable is this SaaS idea? |
| **Copyability Tags** | Can you build a competitor? |

### 📈 What the Data Shows

- **~70%** of tracked AppSumo products are still alive
- **~15%** pivoted to subscription models
- **~15%** shut down completely
- Average LTD-to-subscription transition: **18-24 months**
- Products with **4.5+ ratings** and **50+ reviews** have significantly higher survival rates
